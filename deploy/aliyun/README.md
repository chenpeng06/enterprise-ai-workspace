# deploy/aliyun · 阿里云部署骨架（Phase 1）

Phase 1 只冻结目标拓扑、环境变量边界与成本上限；具体资源编排（Terraform / ROS /
Serverless Devs）、Dockerfile 与 CI 流水线在 Phase 4 交付。

## 目标拓扑

```
                    ┌────────────────────────────┐
  用户 / 浏览器 ───▶ │ CDN + WAF（可选）            │
                    └─────────────┬──────────────┘
                                  ▼
                    ┌────────────────────────────┐
                    │ SLB / Nginx（HTTPS 终结）    │
                    └──────┬──────────────┬──────┘
                           ▼              ▼
                 ┌─────────────────┐  ┌───────────────────┐
                 │ ECS / SAE       │  │ OSS（文档原文）     │
                 │ gateway-go      │  └───────────────────┘
                 └────┬───────┬────┘            ▲
                      │       │                 │ 预签名 URL
                      ▼       ▼                 │
        ┌─────────────────┐  ┌──────────────────┴────┐
        │ RDS PostgreSQL  │  │ ECS / SAE / FC        │
        │ + pgvector      │◀─│ ai-engine-py          │
        └─────────────────┘  └───────────────────────┘
                      ▲                 │
                      │                 ▼
                 ┌─────────┐     ┌──────────────┐
                 │ Redis   │     │ 百炼 DashScope│
                 │（限流）  │     │ LLM/Embedding │
                 └─────────┘     └──────────────┘
```

### 组件选型与边界

| 能力 | 推荐产品 | 说明 |
| --- | --- | --- |
| 网关 | ECS 按量/包月 或 SAE | Go 常驻进程，SSE 长连接；SLB 需关闭响应缓冲 |
| AI 引擎 | ECS 或 SAE（最小 2C4G） | 文档解析与 Embedding 为 CPU/网络密集型；可拆出 FC 异步任务 |
| 数据库 | RDS PostgreSQL 15+（pgvector） | 需确认实例支持 `vector`、`pg_trgm` 扩展 |
| 缓存/限流 | 云数据库 Redis 社区版 | 令牌桶 Lua 脚本 + 限流事件缓冲 |
| 对象存储 | OSS 标准存储 | 原文、抽取文本、导出报告；生命周期转低频 |
| 异步摄取 | 函数计算 FC（可选） | OSS 事件触发解析任务；也可由引擎内置 worker 消费任务表 |
| 可观测 | SLS + 云监控 | 结构化日志、TTFT/错误率告警 |

## 成本约束（月度 ≤ 1000 元）

Phase 4 必须给出一张可核算的账单。当前约束：

- 优先选择按量付费 + 包月混合：RDS 最小规格、Redis 最小规格；
- AI 引擎与网关尽量复用一台 ECS（2C4G）避免多实例固定成本；
- OSS 使用低频访问层 + 生命周期规则；日志保留 30–90 天；
- LLM/Embedding 调用按量计费，设置租户级预算与限流；
- 预留 10%–15% 波动缓冲，最终方案在 Phase 4 以阿里云价格计算器实测。

## 生产环境变量

分别参考 `gateway.env.example` 与 `ai-engine.env.example`，注入到密钥管理
（KMS / SAE 环境变量 / OSS 参数仓库），严禁提交真实密钥。至少需要替换：

- `INTERNAL_TOKEN`（≥ 32 字符，网关与引擎一致）；
- 数据库与 Redis 密码；
- `LLM_API_KEY`、OSS 访问密钥；
- `CORS_ORIGINS`、OSS 预签名域名。

## Phase 4 交付清单（预告）

1. 各服务多阶段 `Dockerfile`（非 root、健康检查、只读根文件系统）；
2. `docker-compose.yml` 完整 stack 与依赖健康门控；
3. 阿里云部署文档：RDS/Redis/OSS 初始化、SLB SSE 配置、FC 事件驱动、
   SLS 采集、备份与回滚；
4. 成本核算表与压测报告（TTFT、并发限流、故障转移）。
